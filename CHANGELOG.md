# Журнал изменений

## 2026-11-10 — Редизайн главной, серверный ключ Supabase

### Добавлено
- Новая главная в духе Rhubarb: hero из двух фото с зазором, монограмма «А/А»,
  затемнение при наведении и подъём при скролле.
- Секция «О нас» с коротким текстом и видео, которое запускается при появлении в кадре.
- Меню из базы: вкладки категорий, карточки блюд, окно блюда с составом и количеством.
- Галерея «Наши работы» (6 работ, подписи при наведении).
- Новые контакты: телефон, почта, Telegram, ВК, адрес, режим работы + форма заявки.
- Футер с разделами и ссылкой «Создано OWS Studio».
- API `POST /api/lead` — заявка сохраняется в таблицу `leads` и уходит письмом.
- `CHANGELOG.md` — этот файл.

### Изменено
- `src/app/page.tsx` сокращён с 1449 до 334 строк: удалены мёртвые секции
  (`Nav`, `Hero`, `RecipesSection`, `AboutSection`, `ContactsSection`, `MenuSection`, `Footer`).
- Корзина и отзывы переведены в светлую тему.
- Видео `public/video/hero.mp4` сжато с 16,5 МБ до 0,99 МБ (1280px, crf 27, без звука),
  водяной знак KlingAI обрезан.

### Исправлено
- Supabase-клиент стал ленивым (`getSupabase()`): сборка больше не требует секретов
  и не падает в Docker без переменных окружения.
- Для всех API-роутов, читающих базу, добавлен `force-dynamic` — они не пытаются
  статически генерироваться при сборке.

### Инфраструктура
- Деплой на web-1 (`deploy.yml`) переведён в ручной режим (`workflow_dispatch`),
  в контейнер прокинуты `SUPABASE_URL` и `SUPABASE_SERVICE_KEY`.
- Прод-сайт собирается Vercel из ветки `main`.

### Затронутые файлы
`src/app/page.tsx`, `src/components/*`, `src/app/api/lead/route.ts`,
`src/app/api/{menu,comments,orders}/**`, `src/lib/supabase.ts`, `src/lib/menu-store.ts`,
`.github/workflows/deploy.yml`, `public/video/hero.mp4`, `public/images/video-poster.jpg`

## 2026-11-09 — Безопасность админки

### Добавлено
- Сессия админки в HttpOnly-cookie с HMAC-подписью и сроком 8 часов.
- Роуты `POST /api/admin/logout`, `GET /api/admin/session`.

### Исправлено
- Закрыты пишущие API без авторизации: `dishes`, `categories`, `upload`, `orders`.
  Раньше любой мог изменить цену или удалить блюдо одним запросом.
- Список заказов (имена и телефоны клиентов) больше не отдаётся без входа.

### Затронутые файлы
`src/lib/admin-auth.ts`, `src/app/api/admin/**`, `src/app/api/menu/**`,
`src/app/api/orders/**`, `src/app/admin/page.tsx`

## 2026-11-06 — Аудит проекта

### Найдено
- Код обращался к колонке `dishes.category`, которой в базе нет (там `category_id`) —
  меню всегда отдавало 3 заглушки вместо 46 блюд.
- 23 из 46 картинок ссылались на несуществующие файлы.
- Таблица `leads` была закрыта RLS без политик — заявки не сохранялись.

### Сделано
- Сверена схема базы с кодом, восстановлены цены и изображения.
- Добавлена политика вставки для `leads`, проверена запись заявки.

## Как ведётся

- Каждое изменение попадает сюда одной записью: дата, суть, файлы.
- Технические решения фиксируются с причиной, а не только с результатом.
- Журнал дополняется до коммита, чтобы история в git и здесь совпадали.
